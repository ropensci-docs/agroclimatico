# Observaciones diarias de estaciones meteorológicas.

Los datos provienen de 2 estaciones del INTA. Ver
[`metadatos_nh()`](https://docs.ropensci.org/agroclimatico/reference/metadatos_nh.md)
para más información y metadatos de las estaciones.

## Uso

``` r
NH0358

NH0114
```

## Formato

NH0358 es un data.table con 25515 filas y 25 columnas

NH0114 es un data.table con 24041 filas y 25 columnas

## Ver también

[`metadatos_nh()`](https://docs.ropensci.org/agroclimatico/reference/metadatos_nh.md)
devuelve los metadatos de las estaciones meteorológicas.
