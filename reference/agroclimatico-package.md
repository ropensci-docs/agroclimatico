# agroclimatico: Índices y Estadísticos Climáticos e Hidrológicos

Conjunto de funciones para calcular índices y estadísticos climáticos
hidrológicos a partir de datos tidy. Incluye una función para graficar
resultados georeferenciados y e información cartográfica.
